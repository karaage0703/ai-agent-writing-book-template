# 技術書の章レビュー

## 入力

- 対象の章
- 本の対象読者と読後のゴール
- 本全体の中心メッセージ
- 必要に応じて前後の章

## 手順

1. 章の結論を一文で要約する
2. 事実、著者の経験、意見、推測を区別する
3. 根拠のない数値、固有名詞、引用を列挙する
4. 他章との重複、矛盾、論理の飛躍を確認する
5. 用語と表記の揺れを確認する
6. 見出しに読点、句点、感嘆符、疑問符、コロンが入っていないか確認し、句読点へ頼らない短い見出しへ直す
7. 初めて読む人に通じない道具名や内部名を指摘する
8. 原文を勝手に書き換えず、理由を添えた修正案を示す
9. `rg -n 'https?://' <対象章>`でリンクを列挙し、参照先と本文の対応を確認する
10. 修正後は`make book`を実行し、PDFの該当ページとEPUBの目次を確認する

## 出力

- 公開前に確認が必要な問題
- 内容を改善する提案
- 確認済みの項目

引用許諾や公開可否など、人間が判断すべき項目を明示する。

## 使用例

```text
book-reviewスキルを使ってchapters/ch03.mdをレビューしてください。
```
