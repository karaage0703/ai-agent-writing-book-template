# 書籍の生成と検査

## 入力

- `book_config.yaml`
- `chapters/`のMarkdown原稿
- `assets/`の表紙と図版

## 手順

1. `AGENTS.md`と`book_config.yaml`を読む
2. `make book`を実行する
3. エラーがあれば、最初に失敗した工程と原因を調べる
4. 原稿、設定、画像、テンプレートを修正し、成功するまで再生成する
5. PDFの判型、表紙、目次、全章、図、コード、奥付を確認する
6. EPUBのアーカイブと目次を確認する
7. 表紙、目次、変更した章の先頭、図とコードのあるページ、奥付を完成形式で見る
8. 変更ファイル、最初の失敗と修正、検査結果、目視したページ、未確認事項を報告する

## 出力

- 生成したPDFとEPUBのパス
- 総文字数、PDFページ数、生成物のSHA-256
- 実行した検査と結果
- 目視したページ
- 未確認事項

生成物を直接編集せず、修正はMarkdown、設定、画像、テンプレートへ戻す。

push、Pull Request、Release、販売ページへのアップロードなど、外部へ影響する操作は人間の確認後に行う。

## 使用例

```text
book-buildスキルを使って、この本をPDFとEPUBへ組版してください。
```
