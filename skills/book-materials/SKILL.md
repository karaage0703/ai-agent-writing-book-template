# 執筆材料の探索

## 入力

- 章の目的と対象読者
- 検索してよいディレクトリや資料
- 対象期間とキーワード

## 手順

1. 検索対象と、対象外にする秘密情報を確認する
2. `rg --files <対象>`でファイルを把握し、`rg -n -i '<キーワード>' <対象>`でファイル名だけでなく本文を検索する
3. 0件または少数なら検索語を短くするか、固有名詞へ変えて一度再検索する
4. 抜粋だけで判断せず、採用候補の元ファイルを読む
5. 候補ごとに、含まれる経験、事実、数値、意見を整理する
6. 公開済み、未公開、第三者の発言を区別する
7. 重複をまとめ、章を書くために不足している情報を挙げる

## 出力

- 材料の要約と元ファイルまたはURL
- 本文へ使える範囲
- 著者へ確認する項目

検索結果にない出来事や経験を補わない。

## 使用例

```text
book-materialsスキルを使って、materials/と公開済みブログから「文字起こし」の材料を探してください。
```
