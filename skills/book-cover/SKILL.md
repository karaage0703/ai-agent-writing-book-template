# 表紙の生成と文字合成

## 入力

- 書名、副題、著者名
- 本の対象読者、中心メッセージ、特徴
- 判型、必要な画像サイズ、希望する雰囲気

## 手順

1. 本の内容と特徴を一文にまとめ、表紙へ必要な要素を絞る
2. 画像生成機能を使う場合は、文字、ロゴ、透かしを描かない背景として生成する
3. 背景の利用条件、生成日、使用した指示を記録する
4. 書名、副題、著者名を同梱スクリプトで合成する
5. 文字と重要な絵が重ならない余白を確保する
6. 原寸、サムネイル、グレースケールで可読性を確認する
7. PDF、EPUB、販売ページ用画像へ同じ版を使う

## 出力

- 文字なし背景
- 文字を合成した表紙
- 合成条件と利用条件の記録

## 実行コマンド

```bash
uv run --with pillow skills/book-cover/scripts/book_cover.py \
  --background assets/cover-background.png \
  --title "書籍タイトル" \
  --author "著者名 著" \
  --output assets/cover.png \
  --style default \
  --preview
```

書名を画像生成モデルへ直接描かせた結果を完成版にしない。日本語の誤字と再現性を避けるため、文字は別工程で合成する。

## 完了条件

- 文字なし背景と文字合成済み表紙が別ファイルで残っている
- 上のコマンドを再実行して同じ文字配置を作れる
- 原寸とサムネイルで書名、著者名を読める

## 使用例

