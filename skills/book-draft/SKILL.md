# 章の作成

## 入力

- 章で読者へ伝えること
- 対象読者と読後のゴール
- 確認済みの材料と出典
- 前後の章と重複を避けるための目次

## 手順

1. 章の結論を一文で置く
2. 読者の疑問に沿って見出しを作る
3. 著者の経験と一般的な説明を区別して書く
4. 数値、引用、固有名詞へ出典または確認メモを付ける
5. 材料にない経験や結果を作らない
6. 次の章へつながる短い結びを付ける
7. 元材料を変更せず、原稿を`chapters/`の別ファイルへ保存する
8. `git diff -- <原稿>`で追加内容を確認し、`make book`で完成形式まで生成する

## 出力

- `chapters/`へ保存するMarkdown原稿
- 未確認の事実と不足材料
- 他章と重複する可能性がある箇所
- `make book`の結果と、生成したPDF・EPUBのパス

## 使用例

```text
book-draftスキルを使って、materials/interviews/20260830_ch03_interview.mdから第3章の叩き台を作ってください。
```
