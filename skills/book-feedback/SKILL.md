# 販売後の反応整理

## 入力

- 読者の感想と問い合わせ
- 告知記録と公開日
- 利用できる場合は販売数などの実測値
- 本文で扱うソフトウェアやサービスの変更

## 手順

1. 取得してよい情報と期間を確認する
2. 事実、読者の意見、著者の推測を分ける
3. 日付、対象版、該当章を揃える
4. 誤り、分かりにくさ、追加要望、環境変化に分類する
5. 影響範囲と確認方法を添えて改訂候補にする
6. 個人情報や非公開の販売情報を公開原稿へ混ぜない
7. `materials/feedback/feedback.csv`へ`date,source,edition,chapter,type,summary,next_action`の列で追記する
8. 改訂した項目は、対応したcommitまたは版番号を記録する

## 出力

- 時系列の反応一覧
- 優先度と根拠を付けた改訂候補
- 次の版で確認する項目

## 使用例

```text
book-feedbackスキルを使って、読者の感想と改訂メモを整理してください。
```
